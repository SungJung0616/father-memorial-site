# 디자인 시스템

## 디자인 방향

성균관대학교 공식 사이트의 단정하고 학술적인 인상을 참고하되, 추모 사이트의 정서에 맞게 대비와 채도를 낮춘다. 학교 사이트를 그대로 복제하지 않으며 성균관대학교의 로고나 공식 마크는 별도 허가 없이 사이트 브랜드처럼 사용하지 않는다.

## 공식 사이트에서 확인한 주요 색상

2026-08-28 현재 렌더링된 성균관대학교 메인 및 교원정보 페이지의 CSS 색상을 기준으로 한다.

| 역할 | 색상 | 출처·용도 |
|---|---|---|
| 교수 프로필 블루 | `#557AC1` | 교원정보 페이지의 주요 블루 배경 |
| 라이트 블루 | `#9ACBF7` | 교원정보 페이지의 보조 강조 |
| 성균관대 메인 오렌지 | `#ED7D31` | 메인 사이트 강조 텍스트·선 |
| 딥 블루 | `#004483` | 메인 사이트 보조 강조 |
| 딥 그린 | `#104330` | 메인 사이트 보조 영역 |
| 본문 | `#333333` | 공통 본문색 |
| 보조 본문 | `#666666` | 설명과 메타데이터 |
| 옅은 회색 | `#F1F2F2` | 메인 사이트 배경 |
| 경계선 | `#E8E8E8` | 카드·구분선 |
| 흰색 | `#FFFFFF` | 기본 카드 배경 |

## 추모 사이트 권장 팔레트

```css
:root {
  --color-primary: #557ac1;
  --color-primary-deep: #004483;
  --color-primary-soft: #eaf1fb;
  --color-heritage: #104330;
  --color-accent: #ed7d31;
  --color-background: #f7f6f2;
  --color-surface: #ffffff;
  --color-text: #333333;
  --color-text-muted: #666666;
  --color-border: #e8e8e8;
}
```

## 사용 비율

- 따뜻한 백색·회백색 배경: 65%
- 흰색 카드와 사진 여백: 20%
- 블루 계열: 10%
- 딥 그린: 4%
- 오렌지 포인트: 1%

## 적용 규칙

- `#557AC1`: 메뉴 선택, 주요 버튼, 링크, 연보 표시
- `#004483`: 제목, 푸터, 중요한 정보
- `#104330`: 생애·가르침·학술 기록의 차분한 보조 영역
- `#ED7D31`: 활성 탭 밑줄, 작은 아이콘, 날짜처럼 매우 제한된 강조
- 본문 배경은 순백색만 사용하지 않고 따뜻한 `#F7F6F2`를 사용한다.
- 장례·추모 사진 영역에서는 오렌지 사용을 피하고 블루·회색만 사용한다.
- 한국어와 영어에서 색상 의미와 계층을 동일하게 유지한다.

## 분위기 키워드

- 단정함
- 학문적 품위
- 따뜻한 기억
- 조용한 존경
- 세대를 잇는 기록관

## 랜딩 페이지 표현 원칙

- 첫 화면은 넓은 사진, 절제된 글자와 충분한 여백을 중심으로 한다.
- 대학·연구기관 사이트의 신뢰감과 현대적인 사진 아카이브의 몰입감을 결합한다.
- 메뉴바는 처음에는 히어로 위에 자연스럽게 놓이고 스크롤하면 읽기 쉬운 고정형으로 바뀐다.
- 히어로 전환 효과는 느리고 조용해야 하며 자동으로 빠르게 움직이지 않는다.
- 스크롤 애니메이션은 짧은 페이드와 이동만 사용하고 장식적인 효과를 피한다.
- 사진이 주인공이 되도록 카드, 테두리와 그림자를 남용하지 않는다.
- 본문은 잡지형 편집 레이아웃처럼 사진과 짧은 이야기가 번갈아 이어지게 한다.
- 모바일을 축소판으로 만들지 않고 제목 길이, 사진 자르기와 버튼 위치를 별도로 조정한다.
- `prefers-reduced-motion` 설정을 존중하고 키보드 접근성과 색상 대비를 유지한다.

## 히어로 후보 형식

### A. 한 장의 대표 초상

가장 정중하고 집중도가 높다. 첫 공개 버전의 기본안으로 권장한다.

### B. 3–5장의 느린 사진 전환

가족, 친구, 연구와 교육의 모습을 함께 보여줄 수 있다. 사진 선정과 모바일 초점 검수가 필요하다.

### C. 대표 초상과 작은 기억 사진 콜라주

풍부한 삶을 보여주지만 첫 화면이 복잡해질 수 있으므로 자료 정리 후 검토한다.
