# 사진 아카이브 설계 및 사전 결정 사항

상태: 논의 중 — 아직 사이트 코드에는 적용하지 않음

## 결정된 방향

- 홈과 전체 사진 아카이브를 분리한다.
- 홈에는 대표 사진과 최근 기록만 노출한다.
- 전체 사진은 `/photos`에서 탐색한다.
- 자동 추출값과 AI 분류값은 확정하지 않고 관리자 검토용 제안으로 저장한다.
- 방문자가 사진 속 인물, 장소, 시기와 추억을 제안할 수 있게 한다.

## 권장 페이지

- `/photos`: 전체 사진과 검색
- `/photos/albums`: 앨범·관계별 탐색
- `/photos/timeline`: 연도·생애 시기별 탐색
- `/photos/people`: 함께한 사람별 탐색
- `/photos/[photoId]`: 사진 상세, 인물, 장소, 관련 추억과 댓글
- `/albums/[albumId]`: 가족, 선림중, 경기고, 서울약대, 후암동, 성균관대 등

## 자동 추출과 제안

- EXIF 촬영일, GPS, 촬영 기기, 방향과 해상도
- 동영상 촬영 시각과 재생 길이
- 연도·장소·행사 묶음 후보
- 중복·유사 사진, 사진 속 글자, 품질 문제
- 얼굴과 인물 후보는 사용할 경우에도 관리자 확인 전 공개하지 않는다.

## 신뢰도 값

- 확정: 가족 또는 관리자가 원자료로 확인
- 기여자 제공: 사진 제공자나 지인이 입력
- 메타데이터: 파일에서 자동 추출
- AI 추정: 시스템 제안, 미확인
- 미상: 확인 불가

## 중요한 예외

- 카카오톡·문자·SNS 사진은 메타데이터가 사라질 수 있다.
- 스캔 사진의 파일 날짜는 실제 촬영일이 아닐 수 있다.
- 파일 수정일을 촬영일로 단정하지 않는다.
- GPS는 자동 추출하더라도 공개 화면에는 기본적으로 표시하지 않는다.

## 첫 공개 전에 정할 것

- [ ] 기본 사진 화면: 전체 / 앨범 / 연도별
- [ ] 1차 대표 사진 30–60장
- [ ] 장례·추모 사진 공개 범위
- [ ] 원본 다운로드 권한
- [ ] 얼굴 인식 사용 여부
- [ ] 방문자 제안의 익명 허용 여부와 연락처 수집 여부
- [ ] 댓글 즉시 공개 또는 승인 후 공개
- [ ] 삭제·비공개 요청용 운영 이메일
- [ ] 사진·영상 허용 형식, 최대 용량과 한 번에 올릴 수 있는 수
- [ ] 원본·웹용 사본·백업 보존 정책
- [ ] 기본 정렬과 연도 미상 사진의 위치
- [ ] 생존 인물, 미성년자와 위치 정보 공개 원칙

## 권장 기본값

- 기본 화면은 앨범과 추천 사진, 전체 사진은 별도 탭
- 1차 공개에서는 얼굴 인식 사용 안 함
- 메타데이터 추출은 사용하되 GPS는 비공개
- 댓글과 방문자 제안은 관리자 승인 후 공개
- 원본은 비공개 보존, 사이트에는 최적화된 사본만 표시
- 삭제 요청이 접수되면 우선 숨기고 가족이 검토

## 보류된 결정

1. 기본 사진 화면
2. 얼굴 인식 도입 여부
3. 익명 정보 제보 방식
