# 개발 착수 전 체크리스트

## A. 시작 전에 반드시 결정할 것

### 1. 기본 사실

- [ ] 사이트에 표시할 최종 성함과 호칭
- [ ] 출생일과 소천일·시간·연도 확인
- [ ] 영문 성함의 공식 표기 확인
- [ ] 대표 약력의 가족 최종 검수
- [ ] 대표 사진 최대 5장, 표시 순서와 첫 화면 추모 문구 확정

### 2. 1차 공개 범위

- [ ] 전체 공개 / 링크를 아는 사람 / 회원 전용 중 선택
- [ ] 장례식 사진의 공개 수준 결정
- [ ] 장지 명칭과 상세 위치의 공개 수준 결정
- [ ] 사진 속 생존 인물의 이름을 표시할 기준 결정
- [ ] 삭제·수정 요청을 받을 운영 이메일 결정

권장 기본값: 사이트는 공개하되 장례 사진은 선별 공개, 장지 상세 위치는 모임 참가자에게만 제공한다.

### 3. 관리자와 권한

- [ ] 최초 최고관리자 1명 지정
- [ ] 비상시 대신 관리할 가족 관리자 1명 지정
- [ ] 제자가 관리 보조를 할 수 있는지 결정
- [ ] 관리자별 권한 구분: 전체 관리 / 콘텐츠 편집 / 승인만 가능
- [ ] 계정 복구 방법과 2단계 인증 결정

권장 기본값: 가족 2명이 최고관리자이고, 다른 보조자는 원본 삭제 권한을 갖지 않는다.

### 4. 자료 규모 확인

- [ ] 아버님 컴퓨터의 사진·영상 전체 용량 확인
- [ ] 사진 파일 개수와 영상 파일 개수 확인
- [ ] 외장하드, 휴대폰, USB, 클라우드에 흩어진 자료 위치 기록
- [ ] 중복 파일이 어느 정도인지 확인
- [ ] 컴퓨터 원본의 백업 사본을 먼저 생성

개발 전에 최소한 `총 사진 수 / 총 영상 수 / 전체 GB` 세 숫자는 알아야 AWS 저장 구조와 업로드 방식을 확정할 수 있다.

### 5. MVP 범위

- [ ] 첫 공개일 결정
- [ ] 첫 공개 사진 수 결정: 권장 30–60장
- [ ] 첫 공개 영상 수 결정: 권장 0–3개
- [ ] 방문자 업로드를 첫날부터 열지 결정
- [ ] 성묘 모임 기능을 첫날부터 포함할지 결정

권장 기본값: 홈, 삶, 가르침과 연구, 사진 30–60장, 추억 제보 폼, 관리자 승인 기능까지만 먼저 공개한다.

### 6. 한국어·영어 정책

- [ ] 첫 공개 시 모든 페이지를 완전한 한영으로 제공할지 결정
- [ ] 방문자가 한국어로 쓴 추억의 영어 번역 주체 결정
- [ ] 영문 고유명사 표기 기준 확정
- [ ] 번역 검수 담당자 지정

권장 기본값: 핵심 고정 페이지는 한영 완성 후 공개하고, 방문자 추억은 원문을 먼저 공개할 수 있으며 영어에는 `번역 준비 중`을 표시한다.

### 7. 계정·배포·도메인

- [ ] 코드 저장소 소유 계정 결정
- [ ] 기존 Netlify 계정에서 별도 사이트 생성
- [ ] AWS 리전 결정
- [ ] 별도 S3 버킷과 최소 권한 사용자 구성
- [ ] 도메인 후보와 등록자 결정
- [ ] AWS Budgets 비용 알림 수신 이메일 결정

권장 기본값: Netlify는 기존 계정을 사용하되 사이트와 환경변수는 완전히 분리하고, AWS 운영 자원에는 추모 사이트 전용 이름을 사용한다.

### 8. 방문자 업로드 동의

- [ ] 사진을 게시할 권한이 있다는 확인 문구
- [ ] 사진 속 다른 인물의 요청 시 내릴 수 있다는 안내
- [ ] 운영자가 편집·압축·번역할 수 있다는 동의
- [ ] 제출자 연락처의 이용 목적과 보관 기간
- [ ] 신고와 삭제 요청 처리 기준

## B. 개발 중 결정해도 되는 것

- [ ] 정확한 글꼴 조합
- [ ] 갤러리 카드 모서리와 그림자 정도
- [ ] 사진 정렬 기본값
- [ ] 세부 애니메이션
- [ ] 기일 알림
- [ ] QR 추모패
- [ ] 영상·음성 전용 아카이브
- [ ] PDF 추모집 내보내기

## C. 개발 착수 승인 조건

다음 여섯 항목이 준비되면 개발을 시작할 수 있다.

- [ ] 최종 성함·생몰 정보
- [ ] 대표 사진과 첫 문구
- [ ] 첫 공개 사진 30장 이상
- [ ] 관리자 1명과 운영 이메일
- [ ] 사이트 공개 범위
- [ ] 사진·영상 전체 용량의 대략적인 수치

대표사진과 추모 문구가 아직 확정되지 않아도 임시 콘텐츠로 화면 개발을 시작할 수 있다. 다만 실제 공개 전에는 가족 검수를 완료해야 한다.

## D. 실제 셋업 때 확인할 보안 항목

- [ ] AWS 루트 계정을 일상 작업에 사용하지 않음
- [ ] AWS와 Netlify에 2단계 인증 적용
- [ ] 비밀키를 코드나 Markdown에 저장하지 않음
- [ ] S3 퍼블릭 액세스 차단 유지
- [ ] 관리자 업로드 확장자와 크기 제한
- [ ] 악성 파일 및 스팸 제출 방어
- [ ] 원본 삭제 유예와 복구 정책
- [ ] 월 비용 경고 설정
