# 사용자 흐름

## 공개 사이트와 관리자 페이지

### 공개 사이트

- 누구나 약력, 승인된 사진, 연구 기록과 추억을 본다.
- 방문자는 추억과 사진을 제보할 수 있지만 게시·수정·삭제 권한은 없다.
- 장지 상세 위치와 제한 자료는 권한이 있는 이용자에게만 보인다.

### 관리자 페이지 (`/admin`)

- 관리자 로그인 필수
- 업로드 대기, 정보 입력 중, 번역 검토, 공개 승인, 비공개, 삭제 요청 상태 관리
- 사진·영상 일괄 분류 및 태그 지정
- 한국어 원문과 영어 번역 편집
- 방문자 제보 승인·거절
- 모임 생성과 참가자 관리
- 원본 다운로드와 백업 확인
- 홈 화면의 대표 제목, 생몰 정보, 추모 문구와 대표사진 편집
- 저장 전 미리보기와 예약·즉시 공개
- `대표사진 후보함`에서 사진 선택과 표시 순서 변경

## 휴대폰 업로드

1. 관리자가 휴대폰에서 관리자 페이지에 로그인한다.
2. `사진 추가`를 누르고 사진 보관함 또는 카메라를 선택한다.
3. 여러 장을 한 번에 선택한다.
4. 업로드는 S3로 직접 전송되며 중단 시 재시도할 수 있다.
5. 공통 분류와 태그를 먼저 지정한다.
6. 개별 사진의 제목, 설명, 인물, 날짜를 나중에 보완할 수 있다.
7. 검토 후 공개한다.

휴대폰에서는 한 번에 20–50개 정도를 권장한다. HEIC 사진은 원본을 보존하고 웹 표시용 JPEG/WebP 사본을 자동 생성한다.

## 아버님 컴퓨터에서 대량 업로드

1. 원본 폴더를 연도·모임 단위로 정리하되 파일을 억지로 다시 이름 짓지 않는다.
2. Chrome 또는 Edge에서 관리자 페이지를 연다.
3. 폴더 선택 또는 끌어놓기로 수백 장을 대기열에 넣는다.
4. 브라우저가 S3 멀티파트 업로드로 원본을 직접 전송한다.
5. 체크섬으로 전송 완료를 확인하고 실패한 파일만 재시도한다.
6. 업로드 묶음 전체에 공통 분류·태그·사진 제공자를 적용한다.
7. 썸네일이 생성되면 개별 정보를 보완하고 공개 승인한다.

대량 자료는 업로드 직후 공개하지 않는다. `수집함 → 분류 중 → 검토 완료 → 공개` 순서로 이동한다.

사진 1,000장 이상과 다수 영상이 예상되므로 한 번에 모두 설명하려 하지 않는다. 먼저 원본을 안전하게 수집한 다음 자동 메타데이터 추출, 중복 후보 표시, 묶음 분류를 거쳐 단계적으로 공개한다.

## 홈 화면 편집

1. 관리자가 한국어·영어 대표 제목과 추모 문구를 편집한다.
2. 대표사진 후보함에서 사진을 선택하고 초점을 조정한다.
3. 데스크톱·휴대폰 미리보기를 확인한다.
4. 임시 저장 또는 공개를 선택한다.
5. 기존 공개 버전은 변경 이력으로 남겨 복구할 수 있다.

## 방문자 제보

1. 방문자가 이름, 관계, 연락용 이메일, 설명을 작성한다.
2. 사진이나 짧은 영상을 업로드한다.
3. 게시 권한과 개인정보 안내에 동의한다.
4. 자료는 비공개 제출 버킷에 저장된다.
5. 관리자가 내용과 동의를 확인한다.
6. 승인된 웹용 사본만 공개된다.
