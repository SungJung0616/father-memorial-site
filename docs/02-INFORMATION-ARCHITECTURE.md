# 정보 구조와 화면 구성

## 1. 홈 / Home

### 상단 메뉴바

- 로고 대신 정중한 워드마크: `정영훈 교수님을 기억하며`
- 홈, 교수님의 삶, 가르침과 연구, 사진으로 보는 삶, 추억 나눔, 모임
- 한국어·English 전환
- 스크롤 전에는 사진 위에 가볍게 겹치고, 스크롤 후에는 단정한 배경으로 고정
- 모바일에서는 간결한 메뉴 버튼으로 전환

### 히어로

- 화면을 넉넉하게 사용하는 대표사진
- 성함, 호칭, 생몰 정보와 짧은 추모 문구
- 대표사진은 1장 고정 또는 3–5장의 느린 전환 방식 중 선택
- `교수님의 삶`과 `추억 남기기` 두 개의 명확한 진입 버튼
- 사진의 중요한 얼굴과 피사체가 모바일에서도 잘리지 않도록 초점 위치 저장

### 첫 화면 콘텐츠 흐름

1. 짧은 소개와 삶의 핵심 문장
2. 생애 연보 주요 순간 3–5개
3. 사진으로 보는 삶의 대표 앨범
4. 가르침과 연구의 핵심 기록
5. 제자·친구의 추억 글 일부
6. 추억과 사진을 보내는 참여 안내
7. 다가오는 추모·성묘 모임
8. 차분한 푸터와 운영·삭제 요청 안내

### 관리자 편집 범위

- 메뉴 노출과 순서
- 대표사진, 사진 초점, 어둡기 오버레이
- 한영 제목·추모 문구·버튼 문구
- 히어로 레이아웃과 사진 전환 여부
- 홈에 노출할 대표 사진·연보·추억 선택
- 섹션 공개·비공개와 순서 변경

## 분류 규칙

- `전체`는 데이터 분류가 아니라 공개 승인된 모든 사진을 보여주는 보기다.
- 각 사진은 대표 분류 하나와 보조 태그 여러 개를 가진다.
- 한 사진이 여러 관계에 해당하더라도 파일을 복제하지 않는다.
- 분류와 태그는 관리자 화면에서 추가할 수 있어야 한다.
- 날짜·장소·인물을 모르는 사진도 등록할 수 있으며 방문자가 정보를 제보할 수 있다.
