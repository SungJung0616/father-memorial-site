# 배포·저장·운영 설계

## 권장 AWS 구성

- Netlify Free: 공개 사이트와 관리자 웹 화면의 우선 배포 대상
- Amazon S3 private bucket: 원본 사진·영상과 방문자 제출 자료
- Amazon S3 published bucket 또는 보호된 prefix: 승인된 웹용 이미지·영상
- Amazon CloudFront: 한국과 미국 방문자에게 빠르게 사진 전달
- Amazon Cognito: 관리자 로그인과 역할 권한
- AWS Lambda: 썸네일, WebP/JPEG 사본, 영상 포스터 이미지 생성
- DynamoDB: 사진 메타데이터, 분류, 번역, 승인 상태
- AWS Budgets: 월 비용 경고

## 현재 배포 결정

- 사용자가 기존 `sj` 포트폴리오를 Netlify 무료 플랜에서 운영하고 있으므로 익숙한 배포 흐름을 우선 활용한다.
- 추모 사이트는 기존 포트폴리오에 섞지 않고 Netlify의 별도 사이트로 만든다.
- 별도 저장소, 별도 빌드 설정, 별도 환경변수, 별도 도메인을 사용한다.
- Netlify는 화면 배포를 담당하고 AWS는 사진·영상, 인증, 메타데이터를 담당한다.
- 실제 셋업 직전에는 당시 Netlify 무료 플랜의 대역폭·빌드·함수 제한을 다시 확인한다.

공개 브라우저가 S3 원본 주소를 직접 사용하지 않게 한다. 업로드도 애플리케이션 서버를 통과시키지 않고, 짧게 유효한 presigned URL을 받아 S3로 직접 전송한다.

## 저장 정책

- 원본: 비공개, 수정 금지
- 웹용 사진: 긴 변 2,000px 이하 WebP/JPEG
- 썸네일: 갤러리용 소형 이미지
- 영상: 원본과 웹 재생용 버전을 구분
- 삭제는 즉시 영구 삭제하지 않고 유예 기간을 둔다.
- 오래된 원본의 별도 보존 사본은 S3 Glacier Deep Archive로 이동할 수 있다.

## 월 비용 가정

2026-08-28 기준 단순 추정이다. S3 Standard 첫 구간을 GB당 월 $0.023, Glacier Deep Archive를 GB당 월 $0.00099로 계산한다. CloudFront의 월 1TB 전송과 1,000만 HTTP/HTTPS 요청 무료 범위 안에 있다고 가정한다.

| 원본 용량 | 웹 사본 포함 추정 저장량 | S3 Standard 저장비 | 예상 전체 월 비용 |
|---:|---:|---:|---:|
| 100 GB | 125 GB | 약 $2.88 | 약 $3–7 |
| 500 GB | 625 GB | 약 $14.38 | 약 $15–25 |
| 1 TB | 1.25 TB | 약 $29.44 | 약 $30–45 |
| 2 TB | 2.5 TB | 약 $58.88 | 약 $60–85 |

전체 비용에는 소규모 요청·변환·데이터베이스 비용의 여유분을 포함했다. CloudFront 전송량이 월 1TB를 넘거나 원본 영상을 자주 재생하면 추가 비용이 커질 수 있다.

## 비용 절감 원칙

- 갤러리에서는 원본이 아닌 썸네일과 웹용 사본만 제공한다.
- 동영상은 자동재생하지 않고 사용자가 눌렀을 때만 재생한다.
- 원본 다운로드는 관리자에게만 허용한다.
- CloudFront 캐시를 길게 유지한다.
- 오래된 원본의 보존 사본은 Glacier Deep Archive로 이동한다.
- AWS Budgets에 $10, $25, $50 단계별 알림을 설정한다.

## 백업 주의사항

S3의 내구성이 높아도 실수로 삭제하거나 계정이 침해될 가능성은 별개다. 버전 관리 또는 별도 아카이브 사본을 두고, 가족이 보관하는 외장 저장장치에도 원본 사본 하나를 유지한다.
